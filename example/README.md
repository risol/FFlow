# FFlow example

This is a runnable demo app for the FFlow SDK. It imports the SDK from the parent directory using a local path dependency.

The demo targets Windows, Linux, macOS, and Web. Android and iOS runners are not part of this project.

From this directory:

```powershell
flutter pub get
flutter run -d windows
```

The app demonstrates custom node widgets, typed node data, controlled graph state, node dragging, edge creation, and viewport controls.
